LocalShelf 安卓只读桥接 — 隐私与权限

本应用没有开发者云端、广告或分析 SDK。用户主动开启后，通过私人 Wi-Fi 向持有配对凭据的客户端提供所选目录的书库信息、封面和图片。发送给阅读客户端本身就是网络传输，不是“数据绝不离开手机”。

通过系统文件选择器授权下载目录，只申请读取权限；不修改或删除 EhViewer 原文件。用户选中的 .db 会暂时完整复制到应用缓存（最长 128 MB），随后只查询下载记录和目录映射，正常完成或出错时尝试删除临时副本；进程异常结束可能遗留缓存副本，可通过系统设置清理应用缓存。程序不查询或分享备份中的账号、历史和上游网站 token，但临时副本可能含有这些字段。

应用私有目录保存目录授权、导入的书名／ID／顺序及显示偏好；文件位置与页码索引保存在应用缓存中。配对凭据由 Android Keystore 密钥加密保存在不参与备份的目录；应用设置 allowBackup=false，不承诺所有厂商的设备转移行为均一致。

INTERNET / ACCESS_NETWORK_STATE：局域网服务与网络变化检查。
FOREGROUND_SERVICE / CONNECTED_DEVICE：后台桥接服务与通知。
CHANGE_WIFI_STATE：满足 connectedDevice 前台服务权限前提；不主动更改 Wi-Fi 配置。
WAKE_LOCK：稳定共享模式保持 CPU 唤醒；可能增加耗电。
POST_NOTIFICATIONS：显示桥接是否开启并提供停止按钮。
不申请相机、联系人、位置、广泛存储访问或自动开机启动权限。

停止共享即停止提供图片，保存的配对仍保留。重置配对将轮换 token，使旧二维码与已配对客户端失效，不删除漫画。清除应用数据会删除本地清单与配对，需要重新授权和导入；不是删除源文件的操作。

HTTP 未加密，只限可信私人局域网。六位码有时效与尝试限制，但备用二维码直接包含长期阅读 token；必须像密码一样保管，不能截图公开。不要对公网开放 8088，不使用公共／访客 Wi-Fi。服务端会处理请求来源地址、漫画及页码标识；应用自身不记录访问历史，不保证第三方 HTTP 库或 Android 系统异常日志绝无连接信息。分享日志前必须脱敏。

下载列表按导出数据库的 TIME 降序查询结果保存。同时间记录的相对顺序未经独立确认，应用会标记待核对；不承诺所有版本 EhViewer 的列表都能无损还原。新增漫画仍需重新导出并导入兼容 .db。

本项目不是 EhViewer 官方应用，也不附带漫画或内容账号。仅分享你有权访问和分享的文件。开源许可不授予漫画版权或第三方商标权。
