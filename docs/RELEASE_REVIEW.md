# 公开源码准备检查

范围：iOS 0.4.13（39）＋安卓只读桥接 0.3.5-dev（14）。本文件不含设备信息、个人环境路径、真实书库统计或历史测试日志。

## 已完成的整理

- 从文件白名单创建独立公开目录，没有复制旧开发记录、版本历史、个人头像、数据库、凭据、设备日志或证书。
- iOS 个人签名团队与 Xcode 用户状态不随包分发；两端使用新的 eh 图标。图标 PNG 仅保留像素和必要色彩信息，移除未审查的附加元数据。
- 模拟器的示例私网地址与书库总数替换为独立测试值；测试 token 为明确构造的假数据，不是真实凭据。多帧样本是 32×32 合成色块。
- MIT 版权行保留维护者明确指定的公开昵称；第三方许可证中的原作者署名和 NOTICE 保留，不能当作个人信息删除。
- 安卓运行时依赖清单已核实为 NanoHTTPD 2.3.1 和 ZXing Core 3.5.3；完整许可随 assets 打包，并增加应用内查看入口。
- iOS 补充 PrivacyInfo.xcprivacy，声明本地设置、缓存时间戳及应用内计时的用途。
- 增加 README、协议、隐私、安全、贡献和发布说明。不附带网站内容，不宣称官方关系，不混入独立同步工具或 NAS 容器。

## 验证状态

- iOS 真机架构 Release 无签名构建通过（Xcode 26.6 / 17F113），隐私清单已进入 `.app`，plist 校验通过。最终图标元数据规范化后两端增量构建再次通过。
- iOS 193 项纯规则检查通过。3 项定向模拟器界面测试通过：继续阅读与重启、设置／扫码分层边缘返回、安卓／NAS 配置与进度工具。没有重跑全部历史测试，也未测真实 NAS。
- 安卓公开版 Debug 构建通过；实际 runtime classpath 只有声明的两个依赖。逐字节核对 APK 中的六份许可／隐私文件与源码资源一致。
- 安卓 135 项 Java 规则及回环 HTTP 检查通过，另有 1 项合成二维码像素编解码往返通过。没有安装公开版到安卓实机，新增许可查看页面未做实机点击验收。
- 69 项允许发布文件的文本／PNG 结构检查通过（原 67 项源码加 2 张首页截图）。检查了已知个人标识、内部路径、签名配置、常见凭据模式、文档本地链接与二进制资源；保留的昵称仅出现在两份 MIT 版权行，第三方声明保留原作者信息。
- README 补充项目介绍、两端功能与按需阅读流程。iOS 截图从公开版模拟器的合成书库拍摄并人工查看，未使用真实封面、书名、进度或连接信息。安卓使用维护者提供的 0.3.4 实机首页截图，无真实书库内容及配对信息；保留原界面与离线状态，明确与 0.3.5-dev 源码的差异。图片统一为 PNG 并移除附加元数据，没有改写截图中的状态或版本。
- 包内不携带 `.git`、个人签名产物、开发机编译路径、日志或真实内容。发布脚本仅按白名单打包，并固定 ZIP 条目元数据。
